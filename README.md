# Lista de 20 Exercícios em PHP
---
Bem-vindo ao repositório da minha lista de atividades em PHP! Este projeto reúne uma série de 20 exercícios práticos focados em lógica de programação, cobrindo desde operações simples até a manipulação de estruturas de repetição e arrays.

## Estrutura dos Exercícios

Os desafios foram divididos em categorias para cobrir os fundamentos da linguagem:

### 1. Sequenciais (Variáveis e Operadores)
* **1. Soma:** Operação básica com dois números inteiros.
* **2. Média:** Cálculo da média aritmética de três notas.
* **3. Metros para Centímetros:** Conversão simples de unidades de medida.
* **4. Área do Retângulo:** Cálculo de área baseado em base e altura.

### 2. Condicionais (If / Else)
* **5. Positivo ou Negativo:** Verificação do estado de um número.
* **6. Maioridade:** Validação de idade mínima (18 anos).
* **7. Aprovação:** Checagem de status escolar com base na média final.
* **8. Maior de Dois:** Comparação de magnitude entre duas variáveis.

### 3. Condicionais (Switch Case)
* **9. Dia da Semana:** Mapeamento numérico de 1 a 7 para os dias correspondentes.
* **10. Vogal ou Consoante:** Análise de caracteres usando o tratamento `strtolower`.
* **11. Status do Pedido:** Sistema dinâmico de mensagens amigáveis para e-commerce.

### 4. Laços de Repetição (For, While e Do While)
* **12 a 14 (For):** Contagem padrão, filtragem de números pares e geração automatizada de tabuada.
* **15 e 16 (While):** Criação de contagem regressiva e acumulador de soma de 1 a 100.
* **17 (Do While):** Sistema de sorteio aleatório contínuo (`rand()`) com contador de tentativas.

### 5. Arrays / Vetores
* **18. Lista de Frutas:** Exibição estruturada em elementos `<li>` usando o laço `foreach`.
* **19. Soma de Array:** Varredura e somatório total de um conjunto numérico.
* **20. Array Associativo:** Manipulação e exibição formatada de dados estruturados (Aluno).

## Como Executar o Projeto

Para visualizar os exercícios rodando localmente com a interface estilizada, siga os passos:

1. Certifique-se de ter um ambiente de servidor local instalado, como o **XAMPP**, **WampServer** ou **Laragon**.
2. Baixe o arquivo `exercicios.php` deste repositório.
3. Cole o arquivo na pasta de arquivos públicos do seu servidor (geralmente a pasta `htdocs` no XAMPP).
4. Inicialize os módulos do **Apache** no painel de controle do seu servidor.
5. Abra o navegador e acesse: `http://localhost/exercicios.php`
